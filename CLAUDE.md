# junior-to-senior

A personal learning curriculum. Read MISSION.md, NOTES.md and the latest file in
learning-records/ before writing a lesson.

## Layout
- lessons/NNNN-slug.html — one self-contained HTML page per lesson, zero-padded number
- reference/*.html — standing reference cards
- learning-records/NNNN-*.md — notes on the learner, one per session
- index.html — GENERATED by build-index.sh from page <title> tags. Never edit by hand.

## Publishing (required after every new or changed lesson)
The site is hosted on GitHub Pages and read on the learner's phone and iPad.
After creating or editing any HTML page, run:

    ./publish.sh "Add lesson 02: information hiding"

This rebuilds index.html, commits, and pushes. Do not skip it, or the lesson
never reaches the learner's devices.

## Lesson pages
- Self-contained: inline CSS and JS. No external assets except Google Fonts.
- Mobile-first: they are read on a phone. Include the viewport meta tag.
- Give each page a descriptive <title>; it becomes the link text on the index.
